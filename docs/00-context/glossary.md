# Glossário

| Termo | Significado no produto planejado |
| --- | --- |
| Aluno | Participante que registra atividades e pode receber treinos de um professor. |
| Professor | Profissional que acompanha alunos com vínculo autorizado. |
| Administrador | Perfil proposto para suporte e moderação, com acesso mínimo necessário. |
| Atividade | Registro de uma prática física; não é sinônimo de publicação pública. |
| Treino | Prescrição organizada de exercícios. |
| Execução | Registro de realização de uma versão do treino. |
| Grupo | Conjunto de participantes com regras de ingresso e visibilidade. |
| Desafio | Objetivo compartilhado com período e métrica definidos. |
| Pontos | Crédito interno de engajamento, sem valor financeiro definido. |
| Ranking | Ordenação segundo métrica, período e escopo explícitos. |
| Título / medalha | Reconhecimento por critério verificável; regras ainda pendentes. |
| RAG | Recuperação de documentos para fundamentar respostas; não implementada. |
| Manifesto | Catálogo local de documentos com identidade, metadados e hash. |
| Indexável | Elegível para futura recuperação, sem significar que já foi indexado. |

Regras específicas ficam nos [documentos de funcionalidades](../03-features/social-feed.md).
